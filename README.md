# Aplicação CLI com Lista

Projeto desenvolvido em Python para a disciplina de Estrutura de Dados do curso de Engenharia de Software.

O objetivo da atividade foi criar uma aplicação interativa utilizando o terminal, em que o usuário consegue executar comandos e manipular informações armazenadas em uma estrutura de dados do tipo lista.

## Sobre o projeto

A aplicação foi desenvolvida utilizando uma implementação própria de `ArrayList`, permitindo trabalhar com operações de inserção, remoção e organização dos elementos.

A lista possui uma capacidade inicial definida e pode aumentar de tamanho automaticamente quando todas as posições estiverem ocupadas.

## Recursos utilizados

Durante o desenvolvimento foram aplicados conceitos como:

- Inserção de dados na lista
- Inserção em uma posição específica
- Remoção do último elemento
- Remoção por posição
- Verificação de lista vazia
- Verificação da capacidade da lista
- Aumento da memória da lista
- Cópia dos elementos para uma nova estrutura
- Exibição dos dados cadastrados
